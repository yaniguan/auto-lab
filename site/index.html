    04 / Workspace CLI & Citation

    Clone, inspect, and verify the stack locally.

    The autolab-hub package uses the Python standard library only and manages all 14 sibling checkouts. 

    git clone https://github.com/yaniguan/auto-lab.git && cd auto-lab
pip install -e ".[dev]"
python scripts/sync_all.py --action clone-or-fetch   # clone or update all 14 sibling repositories
autolab layers                                       # print L6 -> L0 hierarchy
autolab inspect labbench-posttrain                   # print Object, Data, Model, Training, History, Properties
autolab loop --scenario broken_tip_reuse             # trace L4 default-deny block & L3 write-back
